About this workshop

This practical workshop shows educators how to create interactive online lessons for Canvas. Participants will learn two ways to build interactive content. The first method uses Microsoft Learning Zone to create and share lessons quickly. The second method uses artificial intelligence prompts and templates to build custom interactive lessons. The workshop includes examples from UBD language modules, including interactive learning web apps. Participants will follow step by step guidance to create their own content, host it using Google Sites, and publish it in Canvas. During the session, each participant will create at least one interactive lesson and share their work with colleagues.

Intended learning outcomes

By the end of this workshop, you will be able to:

  1. Differentiate and select appropriate digital workflows (Microsoft Learning Zone vs. generative AI templates) based on specific instructional needs.
  2. Design and generate interactive lesson components (such as scenario based formative exercises and interactive activities) using structured AI prompt templates.
  3. Publish and integrate interactive web content into UBD Canvas LMS modules using native HTML embedding and Google Sites.

Before you come

Please get these ready before 11 November so we can spend our time building, not installing.

  • Bring your own laptop. A Windows laptop is preferred, and a Copilot+ PC is even better.
  • Install Microsoft Learning Zone on your laptop before the workshop. 【Download link】
  • Have an AI account ready for ChatGPT, Gemini, or Claude, and check that you can log in. A free account is completely fine.
  • Have a Google account you can use to create a Google Site.
  • Bring some course material: notes, slides, a reading, or a set of questions from one of your modules. A short topic works best.
  • Check your Canvas access: you should be able to edit a Page in at least one course (a sandbox course is ideal).
