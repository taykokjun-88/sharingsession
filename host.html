How to make a token (2 minutes)
  1. On GitHub: your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: tea host panel. Expiration: 30 days.
  3. Repository access: Only select repositories → sharingsession.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copy it, paste it above, press Connect.

The token is kept only in this browser on this device. It can change nothing except the sharingsession repository.
